# 人工智能NLP-RAG项目-11 Embeddings模型微调任务

## 项目概述

本项目的目标是在专业领域数据上微调 Embeddings 模型（BAAI/bge-base-en-v1.5），
以提升 RAG（检索增强生成）系统在特定领域的检索准确性，弥合通用模型与专业领域之间的"语义鸿沟"。

## 需求来源

人工智能NLP-RAG项目-11-Embeddings模型微调任务工单V1.0-20250826.pdf

## 任务描述

通用嵌入模型在大规模网络语料库上预训练，为语义理解提供了良好的起点。但当它们面对小众专业中普遍存在的
专业术语、独特实体和特定语义关联时，其性能可能会下降。医学研究、法律判例、专有工程文档，甚至特定的
金融工具，常常以通用模型尚未充分掌握的方式使用语言。

这种差异，常被称为"语义鸿沟"，可能导致检索结果不理想——系统未能理解用户意图或无法在专业知识库中
找到最相关的文档。

在专业数据上微调嵌入模型是弥补此鸿沟的一种方法，能大幅提升 RAG 系统检索部分的准确性。

## 核心目标

调整嵌入空间，使其更准确地反映与目标专业相关的语义相似性与差异。

## 使用的模型

- **基础模型**: BAAI/bge-base-en-v1.5
- 高性价比文本嵌入模型，MTEB/C-MTEB 基准测试表现优异
- 适合计算资源有限的场景

## 数据集格式与损失函数

| 数据集格式 | 适用损失函数 |
|-----------|-------------|
| 正例对 (相关句子对) | 对比损失 (Contrastive Loss) |
| 三元组 (锚点, 正例, 负例) | 三元组损失 (Triplet Loss) |
| 带相似度分数的句子对 | 余弦相似度损失 (Cosine Similarity Loss) |
| 带类别的文本 | 交叉熵损失 (Cross-Entropy Loss) |
| 可截断嵌入 | 套娃损失 (Matryoshka Loss) |

## 验收标准

微调后的 Embeddings 模型的检索效果比微调前要好，要有数据指标支撑。

## 领域数据

本项目以法律领域为例，包含法律术语、判例引用、法律条文等专业内容。
同时提供医疗领域数据作为扩展。
