# 10个问题 RAG vs 纯 LLM 对比评估（parse2）

## 评估范围
- 样本数：10
- 对比对象：parse2 阶段当前项目 RAG 问答结果 vs 纯 LLM 直接回答结果
- 数据文件：`reports/parse2/golden_set.csv`、`reports/parse2/evaluation_result.csv`

## 评估口径
- 本轮评估降低 `gold_pages` 字段的重要性。
- 若答案内容正确、且 `rag_evidence_preview` 中存在直接支撑证据，即使物理页码与逻辑页码存在偏移，也优先判为正确。
- `rag_page_hit` 仍保留统计，但仅作为辅助观察指标，不作为主结论依据。

## 指标汇总
| 指标 | 数值 |
| --- | --- |
| RAG 正确率 | 10/10 = 100.00% |
| 纯 LLM 正确率 | 2/10 = 20.00% |
| RAG 页码命中率 | 4/10 = 40.00% |
| RAG 证据命中率 | 10/10 = 100.00% |
| RAG 忠实度 | 10/10 = 100.00% |
| 纯 LLM 幻觉率 | 8/10 = 80.00% |
| 纯 LLM 拒答率 | 0/10 = 0.00% |
| RAG 胜出题数 | 8 |
| 纯 LLM 胜出题数 | 0 |
| 平局题数 | 2 |

## 结论
- parse2 阶段的 RAG 在本轮 10 个问题上实现了 10/10 的正确率，明显优于纯 LLM 的 2/10。
- 如果把页码字段降为辅助参考，当前 parse2 的主要能力已经集中体现在“答案正确 + 证据可回溯”这两个方面。
- 当前最明显的剩余问题不是答案本身，而是物理页、逻辑页、结构化字段页三套页码体系仍有偏移，导致 `rag_page_hit` 偏低。

## 主要观察
1. 基础字段题表现稳定：注册资本、法定代表人、重要供应商领域均能稳定命中。
2. 金额/比例题显著提升：军用领域收入、收入占比、补充流动资金金额均已能答对。
3. 纯 LLM 仍存在外推倾向：一旦脱离文档证据，容易补充未在原文中直接出现的行业范围、标准名称或新时间点数据。
4. 页码指标需要单独解释：parse2 中多处答案证据正确，但返回页码对应的是逻辑页或增强页，不一定与 golden_set 中物理页完全一致。

## 建议
- 后续如果继续做验收，建议把“答案正确率”和“证据命中率”作为主指标，把“页码命中率”降级为辅指标。
- 若要进一步提升展示一致性，可单独增加“逻辑页码 -> PDF 物理页码”映射层。
- 若要提升纯 LLM 基线表现，需要更强的提示词约束，避免模型引用招股书之外的公开信息。
