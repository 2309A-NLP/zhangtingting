# 16个问题 RAG vs 纯 LLM 对比评估（parse4）

## 评估范围
- 样本数：16
- 对比对象：parse4 阶段当前项目 RAG 问答结果 vs 纯 LLM 直接回答结果
- 覆盖文档：`招股说明书1` + `招股说明书2`
- 数据文件：`reports/parse4/golden_set.csv`、`reports/parse4/evaluation_result.csv`

## 评估口径
- 本轮评估延续 parse2 的口径，降低 `gold_pages` 字段的重要性。
- 若答案内容正确、且 `rag_evidence_preview` 中存在直接支撑证据，即使物理页码与逻辑页码存在轻微偏移，也优先判为正确。
- `rag_page_hit` 仍保留统计，但主要用于观察页码映射稳定性，不作为主结论唯一依据。

## 指标汇总
| 指标 | 数值 |
| --- | --- |
| RAG 正确率 | 15/16 = 93.75% |
| 纯 LLM 正确率 | 3/16 = 18.75% |
| RAG 页码命中率 | 13/16 = 81.25% |
| RAG 证据命中率 | 15/16 = 93.75% |
| RAG 忠实度 | 16/16 = 100.00% |
| 纯 LLM 幻觉率 | 12/16 = 75.00% |
| 纯 LLM 拒答率 | 0/16 = 0.00% |
| RAG 胜出题数 | 13 |
| 纯 LLM 胜出题数 | 0 |
| 平局题数 | 3 |

## 结论
- parse4 阶段的 RAG 在 16 个问题上达到了 15/16 的正确率，明显优于纯 LLM 的 3/16。
- 当前 parse4 的优势已经不只体现在基础字段题，也体现在表格题、组织结构图题、图表趋势题这几类多模态问题上。
- 当前最主要的剩余问题不是“乱答”，而是个别复杂列表题仍存在答案不完整，以及少数题目的物理页码与检索页码仍有偏移。

## 主要观察
1. 多模态能力开始产生实际收益：组织结构图题和图表趋势题都能稳定答对，说明视觉结果已经真正进入主问答链路。
2. 双招股书统一检索可用：来自两家公司的问题都能正确路由并命中对应证据，没有出现系统性串库。
3. 纯 LLM 依旧容易跳出题目语境：最常见的问题是混入上市后年份、后续再融资方案或行业常识，导致答案偏离招股书原文。
4. 页码指标明显优于 parse2，但仍不是完全稳定：例如图表题和部分基础字段题仍会出现物理页偏移或增强页引用。

## 建议
- 后续验收仍建议把“答案正确率”“证据命中率”“忠实度”作为主指标，把“页码命中率”作为辅助指标。
- 对复杂列表题继续加强表格结构化和答案完整性校验，尤其是募投项目、关联方名单这类覆盖性要求高的问题。
- 保持当前 parse4 的证据优先策略，避免为了自然语言流畅度牺牲答案的可追溯性。
