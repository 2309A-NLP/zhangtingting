# parse4 测评结果报告

## 1. 测评说明
本次测评基于 `parse4` 阶段生成的知识库结果，对两份招股书共 16 个固定问题进行抽样评估，对比当前 RAG 问答链路与纯 LLM 直接回答两种方式。与 parse2 相同，本轮继续降低 `gold_pages` 字段的重要性，更强调三个核心维度：答案是否正确、证据是否能支撑答案、答案是否忠于证据。相比前一阶段，parse4 的问题集覆盖面更广，已经包含基础字段题、表格题、关联方题、金额题、图表趋势题和组织结构图题。

## 2. 总体结果
| 评估项 | 结果 |
| --- | --- |
| RAG 正确率 | 15/16 = 93.75% |
| 纯 LLM 正确率 | 3/16 = 18.75% |
| RAG 页码命中率 | 13/16 = 81.25% |
| RAG 证据命中率 | 15/16 = 93.75% |
| RAG 忠实度 | 16/16 = 100.00% |
| 纯 LLM 幻觉率 | 12/16 = 75.00% |
| RAG 胜出题数 | 13 |
| 平局题数 | 3 |

## 3. 结果解读
从本轮结果看，parse4 已经进入“整体可用”的阶段。RAG 在 16 个问题中答对了 15 个，且 16 个答案都保持了对证据的忠实，没有出现明显脱离招股书内容自由发挥的情况。这一点比单纯的正确率更重要，说明当前链路在生成阶段已经较好地受到了检索证据约束。

与 parse2 相比，parse4 的进步不只体现在正确率，还体现在能力边界的拓展。组织结构图题、图表趋势题这类过去高度依赖视觉理解的问题，现在已经可以稳定走通“检索命中文本块 -> 关联视觉对象 -> 送入问答上下文”的链路，最终给出与招股书一致的答案。这说明多模态结果已经不是旁路信息，而是真正进入了主问答链路。

`RAG 页码命中率` 达到 81.25%，已经明显高于早期版本，但仍不能简单把它等同于答案质量。当前仍有少数题目存在物理页、逻辑页或增强页之间的偏移，例如图表题引用页仍会出现 71/72 或 309/原书页之间的差异，因此这一项更适合作为稳定性观察指标，而不是单独的验收门槛。

纯 LLM 的表现仍然显著弱于 RAG。它在极少数基础字段题上能够答对，但一旦题目涉及招股书中的特定年份、特定表格、特定图表或公司内部组织结构，模型就很容易混入行业常识、上市后公告或其他时间口径信息，导致结果偏离题目限定的招股书语境。

## 4. 表现较好的题目
- 题目 5：组织结构图题。RAG 正确回答了销售部由 4 个部门构成，并指出大客户销售部下设 6 个销售处，说明视觉对象已经可以为主链路提供有效证据。
- 题目 6：图表趋势题。RAG 成功识别出“汽车领域增长率最快、IC 卡市场为负增长”，表明图表类证据已经具备可用性。
- 题目 3、4：关联方题。RAG 不仅能识别“存在控制关系”的关联方，还能给出“不存在控制关系”的企业名单，说明结构化表格与检索的协同效果较好。
- 题目 260、33、207：金额与比例题表现稳定。军用领域收入、收入占比、补充流动资金金额都回答准确，说明当前对表格数值和金额字段的抽取已经具备较高可靠性。
- 题目 95、795：知识型事实题命中准确。技术标准名称和获奖工程名称这类对字符串精度要求较高的问题，RAG 也能稳定答对。

## 5. 平局题说明
- 题目 1：本次发行股数及占比。RAG 与纯 LLM 都回答正确，因此判为平局；但 RAG 仍具备更好的可追溯性。
- 题目 957：公司在哪个领域已成为重要供应商。两者都答到了“国防军队视频指挥领域”，因此判为平局；RAG 的优势仍是证据和页码都可回溯。
- 题目 531：法定代表人是谁。两者都给出“程家明”，属于基础实体题上的平局。

## 6. 仍需关注的问题
- 复杂列表题仍可能不完整。唯一答错的题目是题目 2“本次募集资金拟投资哪些项目”。RAG 已经明显优于纯 LLM，但答案对募投项目的覆盖仍不够完整，说明这类题目仍需要更强的表格结构利用和完整性校验。
- 页码映射仍未完全统一。题目 6 和题目 543 已经说明，即使答案和证据本身正确，返回页码也可能与 golden_set 中记录的物理页码不完全一致。
- 纯 LLM 的外推问题依旧突出。它最常见的错误不是完全不会答，而是混入了上市后年份、其他融资方案或行业常识，这对正式验收是不利的。

## 7. 结论
如果按“答案正确 + 证据支撑 + 忠于原文”作为主标准，parse4 已经明显优于前期版本，也明显优于纯 LLM 直接回答。当前 RAG 的优势不仅体现在单点事实提取，而是已经扩展到表格、图表、组织结构图等更复杂的信息形态上。可以认为 parse4 已经完成了从“能检索到一些相关文本”向“能围绕招股书证据稳定作答”的阶段跃迁。

不过，parse4 还没有完全收尾。后续如果要进一步追求验收质量，重点不应再放在基础事实题，而应集中在复杂列表题完整性、页码统一映射以及少数跨页/多对象证据的展示一致性上。

## 8. 后续建议
1. 对复杂表格题增加“答案覆盖度”校验，避免只答出项目列表中的一部分。
2. 增加统一的页码映射层，把物理页码、逻辑页码、增强页码收敛到同一套展示口径。
3. 继续保留多模态证据进入主链路的策略，尤其是组织结构图、图表趋势题已经证明这条路线有效。
4. 后续如果继续扩展验收集，建议优先补充跨页表格题、同页多表格题和多视觉对象混排题，用来检验 parse4 的上限能力。
