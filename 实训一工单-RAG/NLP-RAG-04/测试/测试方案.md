# NLP-RAG-04 测试方案

## 1. 测试目标

验证 RAG 系统在以下维度的正确性和稳定性：
1. 检索准确性：召回的 chunk 与问题匹配
2. 答案准确性：LLM 答案基于证据且引用正确
3. PDF 解析完整性：文本/表格/图表正确提取和分类
4. 管线稳定性：多步骤编排在各种输入下正确完成
5. 边界情况：空输入、无答案问题、多 PDF、语音输入

---

## 2. 测试层级

### 2.1 单元测试

针对各模块核心函数，不依赖外部服务（Milvus、vLLM、VLM API）。

| 模块 | 测试文件 | 测试内容 |
|------|---------|---------|
| query_understanding.py | test_query_understanding.py | 语言检测、意图分类、字段检测、问题拆分、搜索词扩展 |
| text_utils.py | test_text_utils.py | 分块逻辑、空白规范化、标签推导、chunk_id 稳定性 |
| embedding.py | test_embedding.py | hash 兜底向量生成、维度一致性 |
| vector_store.py | test_vector_store.py | BM25 索引构建与评分、RRF 融合、低价值过滤 |
| rerank_service.py | test_rerank_service.py | 重排接口（mock 模式） |
| config.py | test_config.py | 配置加载、.env 覆盖、路径自动发现 |

**Mock 策略**：
- Milvus 断开时 vector_store 回退到本地 fallback_records 模式（需测试两种模式）
- LLM 调用用预定义响应 mock
- VLM API 用本地缓存数据 mock

### 2.2 集成测试

验证模块间协作，需要 Docker 服务运行。

| 测试内容 | 说明 |
|---------|------|
| 端到端检索 POST /api/query | 验证 citations 包含正确页码和文本 |
| PDF 接入 POST /api/ingest | 验证 Milvus 集合已建、chunk 数 > 0 |
| 语音识别 POST /api/transcribe | 验证转写文本非空 |
| 上传 PDF POST /api/upload-pdf | 验证 uploaded 集合已创建 |
| 健康检查 GET /api/health | 验证各组件状态报告准确 |

### 2.3 答案质量评估

使用预定义测试问题集，人工评估答案质量。

**评估维度**：
- 答案正确性：答案中的事实是否准确
- 引用准确性：引用的页码是否确实包含该信息
- 答案完整性：是否回答全部子问题
- 证据充分性：LLM 是否有足够证据支持答案

**测试问题样例**：

```
# 字段查询类
Q1: 发行人的法定代表人是谁？
Q2: 发行人的注册资本是多少？

# 募集资金类
Q3: 本次募集资金拟投资哪些项目？
Q4: 计划使用多少募集资金用于补充流动资金？

# 发行股数类
Q5: 本次发行多少股？占发行后总股本的比例是多少？

# 组织结构类
Q6: 销售部由几个部门构成？
Q7: 大客户销售部由几个销售处构成？

# 图表趋势类
Q8: 增长率最快的是哪个行业？
Q9: 负增长的是哪个行业？

# 关联方类
Q10: 与公司不存在控制关系的关联方企业有哪些？

# 军用收入类
Q11: 报告期内，来自军用领域的收入是多少？
Q12: 来自军用领域收入占主营业务收入的比重是多少？

# 上游/下游类
Q13: 电子信息行业的上游涉及哪些行业？
Q14: 电子信息行业的下游主要包括哪些行业？

# 技术标准类
Q15: 公司参与制定的技术标准是什么？

# 无答案边界
Q16: 公司去年净利润是多少？（PDF 无此信息时，应返回"未检索到足够证据"）
```

## 5. 评估指标参考

| 指标 | 目标值 | 计算方式 |
|------|--------|---------|
| Citation Accuracy | >= 90% | 引用的页码确实包含该信息 |
| Factual Correctness | >= 85% | 答案中事实陈述准确无误 |
| No-Answer Rate | <= 10% | 应回答的问题返回"未检索到"的比例 |
| Retrieval Recall@5 | >= 80% | 答案所在 chunk 在前 5 个结果中 |
| End-to-End Latency | <= 15s | 从提问到收到答案的总耗时 |
| Milvus Fallback Recovery | 100% | Milvus 断开后自动回退到本地检索 |

```bash
python test/batch_fill_rag_answers.py --input test/questions.csv --output test/results.json

# 查看 VLM 冒烟测试
cat test/pdf_vlm_smoke_test.md
```
