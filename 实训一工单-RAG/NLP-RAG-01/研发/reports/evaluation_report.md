# RAG 问答系统测评结果报告

## 1. 测评说明
本次测评基于《招股说明书1.pdf》构建的 RAG 问答系统展开，使用项目中预设的 10 个必答问题作为标准测试集，对比当前 RAG 系统与纯 LLM 直接问答两种方式的效果。评估重点包括正确率、页码命中率、证据命中率、忠实度以及是否出现幻觉或拒答现象。

## 2. 总体结果
| 评估项 | 结果 |
| --- | --- |
| RAG 正确率 | 3/10 = 30.00% |
| 纯 LLM 正确率 | 0/10 = 0.00% |
| RAG 页码命中率 | 7/10 = 70.00% |
| RAG 证据命中率 | 6/10 = 60.00% |
| RAG 忠实度 | 4/10 = 40.00% |
| 纯 LLM 幻觉率 | 0/10 = 0.00% |
| 纯 LLM 拒答率 | 10/10 = 100.00% |

## 3. 结果解读
当前 RAG 系统在 10 个测试问题中答对了 3 题，明显优于纯 LLM 的 0 题结果，说明检索增强对招股书类长文档问答是有效的。但从整体表现看，RAG 仍然存在较明显的不稳定性，特别是在涉及表格、金额、多期对比数据和相邻相似段落时，容易出现“检索到相关页面但答案生成错误”的情况。

纯 LLM 在本轮测试中全部表现为拒答，没有直接产生明显事实性幻觉，但也没有形成有效回答。因此从业务可用性角度看，纯 LLM 当前不具备独立完成此任务的能力。

## 4. 表现较好的题目
- 题目 957：武汉兴图新科电子股份有限公司在哪个领域已经成为重要供应商？。RAG 回答正确，结论：核心领域回答基本正确，且检索页与证据均命中；后半段有扩展描述，但未影响主结论。
- 题目 543：武汉兴图新科电子股份有限公司注册资本是多少？。RAG 回答正确，结论：金额答案正确，页码和证据均直接命中。
- 题目 531：武汉兴图新科电子股份有限公司法定代表人是谁？。RAG 回答正确，结论：实体答案准确，检索第一页即命中。

## 5. 主要失败题目与原因
- 题目 260：报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？。失败原因：检索页命中 129 页，但生成答案抽取了错误的收入与占比，还把占比误写成收入。
- 题目 95：武汉兴图新科电子股份有限公司参与制定了哪个技术标准？。失败原因：证据片段已接近正确答案，但 RAG 额外编造了标准背景和第二个“技术标准”。
- 题目 33：报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入占主营业务收入的比重分别是多少？。失败原因：检索结果包含 129 页，但答案使用了错误比重并混入了无关收入数据。
- 题目 34：根据武汉兴图新科电子股份有限公司招股意向书，电子信息行业的上游涉及哪些企业？。失败原因：检索和生成都偏离产业链段落，未命中 151 页的上游企业核心证据。
- 题目 793：根据武汉兴图新科电子股份有限公司招股意向书，电子信息行业的下游主要包括哪些行业？。失败原因：检索页包含 151 页，但答案把“电子信息行业下游”答成了“公司产品应用领域”，范围明显扩张。
- 题目 795：武汉兴图新科电子股份有限公司参与的哪个工程荣获了国家科技进步一等奖？。失败原因：检索证据已命中正确工程名称，但生成答案被错误改写成完全不同的奖项。
- 题目 207：武汉兴图新科电子股份有限公司计划使用本次发行募集资金的多少用于补充流动资金？。失败原因：答案来自增资与投资协议片段，不是募投项目表，数值和页面都未命中。

## 6. 问题归因分析
- PDF 表格抽取能力不足：涉及金额、比例、多年度对比的数据题最容易出错。
- 相似段落干扰较强：同一份招股书中财务、行业、项目描述反复出现，导致检索召回后生成阶段容易串段。
- 生成约束不足：即使证据已经命中，模型仍可能进行不必要扩写，造成忠实度下降。

## 7. 结论
本项目当前版本已经具备基础 RAG 问答能力，在基础事实型问题上能够取得可用结果；但若用于正式验收或生产环境，还需要继续增强 PDF 解析质量、表格抽取能力和生成阶段的证据约束机制。现阶段更适合定位为“原型系统”或“可演示版本”，距离高可靠交付还有一定优化空间。

## 8. 后续优化建议
1. 引入更强的 PDF 结构化解析方案，重点提升表格和多栏文本还原质量。
2. 对金额、比例、项目名等关键信息建立规则抽取和答案校验层。
3. 检索阶段增加 rerank，减少相似页面对答案的污染。
4. 生成阶段要求模型严格引用命中的页码和证据，降低自由发挥带来的错误扩写。
