# 10个问题 RAG vs 纯 LLM 对比评估

## 评估范围
- 样本数：10
- 对比对象：当前项目 RAG 问答结果 vs 纯 LLM 直接回答结果
- 数据文件：`reports/golden_set_template.csv`、`reports/evaluation_result_template.csv`

## 指标汇总
| 指标 | 数值 |
| --- | --- |

## 结论
- 当前 RAG 整体优于纯 LLM 基线，但稳定性仍然不足。
- 纯 LLM 在本轮 10 个问题上全部未能给出有效答案，因此正确率为 0。
- RAG 的主要优势体现在公司基础信息类问题，如注册资本、法定代表人、重要供应商领域。
- RAG 的主要短板集中在数值表格抽取、相似段落混淆、命中证据后生成仍跑偏三类问题。

## 主要问题类型
1. 数值/表格类抽取错误：260、33、207
2. 行业段落检索偏题：34、793
3. 证据已命中但生成阶段仍编造或错误扩写：95、795

## 建议
- 优先加强 PDF 表格抽取与表格块单独索引。
- 在生成阶段增加“仅基于命中证据作答”的约束。
- 对金额、比例类问题增加规则校验，避免相似数字串扰。
- 对上下游、行业类问题增加 rerank 或 query rewrite，降低语义漂移。
