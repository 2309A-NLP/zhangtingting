# parse2 测评结果报告

## 1. 测评说明
本次测评基于 `parse2` 阶段生成的知识库结果，对《招股说明书1.pdf》对应的 10 个固定问题进行抽样评估，对比当前 RAG 问答链路与纯 LLM 直接回答两种方式。与 parse1 不同，本轮明确降低了 `gold_pages` 字段的重要性，更强调三个核心维度：答案是否正确、证据是否能支撑答案、答案是否忠于证据。

## 2. 总体结果
| 评估项 | 结果 |
| --- | --- |
| RAG 正确率 | 10/10 = 100.00% |
| 纯 LLM 正确率 | 2/10 = 20.00% |
| RAG 页码命中率 | 4/10 = 40.00% |
| RAG 证据命中率 | 10/10 = 100.00% |
| RAG 忠实度 | 10/10 = 100.00% |
| 纯 LLM 幻觉率 | 8/10 = 80.00% |
| RAG 胜出题数 | 8 |
| 平局题数 | 2 |

## 3. 结果解读
从本轮结果看，parse2 的效果相比早期版本已经有明显提升。RAG 在 10 个问题中全部给出了可接受的正确答案，而且每题都能在检索结果或结构化字段中找到直接支撑证据，因此 `RAG 正确率` 与 `RAG 证据命中率` 都达到了较高水平。相对地，`RAG 页码命中率` 只有 4/10，这并不意味着答案质量差，而是说明 parse2 当前返回的页码体系仍混合了物理页码、逻辑页码以及增强结果中的页码标注，和 golden_set 中记录的页码无法完全一一对应。

纯 LLM 的表现仍然弱于 RAG。它在少数基础实体题上可以给出正确结果，但在金额题、行业题、标准名称题上仍会明显引入文档之外的信息，或者直接切换到其他年份、其他公告口径，因此整体可控性仍不足。

## 4. 表现较好的题目
- 题目 260：军用领域收入分别是多少。RAG 不仅答对了四个金额，还在证据中保留了完整数值串，说明 parse2 对金额类信息的抽取已经具备可用性。
- 题目 33：军用领域收入占主营业务收入的比重分别是多少。RAG 四个比例值均正确，且与证据片段一致。
- 题目 207：本次发行募集资金中用于补充流动资金的金额。RAG 成功从募投表格中提取出 `15,000.00 万元`，这类表格题是 parse2 的重要提升点。
- 题目 543、531：注册资本、法定代表人等基础字段题稳定命中，说明结构化字段增强已经开始起作用。

## 5. 平局题说明
- 题目 957：重要供应商所在领域。RAG 与纯 LLM 都答到了“国防军队视频指挥领域”的核心结论，因此判为平局；不过 RAG 的优势在于有明确证据片段支撑。
- 题目 531：法定代表人是谁。两者都答出“程家明”，因此同样判为平局；RAG 的页码字段虽未与 golden_set 完全一致，但证据是明确的。

## 6. 仍需关注的问题
- 页码映射仍不稳定。当前最主要的短板不是答错，而是答案引用页常常落在逻辑页或增强页，与人工整理的 gold_page 不完全对齐。
- 证据展示仍偏原始。虽然已经能支撑答案，但不少 `rag_evidence_preview` 仍保留较长原始片段，后续可以继续优化展示层，让引用更整洁。
- 纯 LLM 依旧容易外推。尤其是行业题和标准题，模型会补充“看起来合理但文档未明确给出”的内容，这对正式测评是不利的。

## 7. 结论
如果按“答案正确 + 证据支撑”作为主标准，parse2 已经达到了一个明显优于 parse1 的阶段性结果，足以说明当前重构方向是有效的。接下来的重点不再是简单追求更多召回，而是要把页码映射、证据展示、引用一致性这几个体验层问题继续打磨好。

## 8. 后续建议
1. 增加统一的页码映射层，把逻辑页码、物理页码、增强页码统一到同一套展示口径。
2. 对答案中的“引用页码”做展示清洗，避免同一题出现多个不必要的候选页码。
3. 保持当前 parse2 的证据优先策略，不要再让生成模型自由扩写表格之外的信息。
4. 如果后续要做更正式的验收，可以在这套 10 题之外再追加 20 到 30 题，重点覆盖复杂表格、多期财务数据和跨页内容。
