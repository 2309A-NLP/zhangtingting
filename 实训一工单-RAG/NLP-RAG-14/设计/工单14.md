#### 一、技术总结文档

**1. RAGFlow PDF解析流程梳理**

| 解析器类型        | 触发条件                  | 分块策略                                        | 技术实现                                               |
| :---------------- | :------------------------ | :---------------------------------------------- | :----------------------------------------------------- |
| `paper`           | PDF文件，parser_id=paper  | 按章节/段落分块，提取标题、摘要、正文、参考文献 | DeepDoc识别版面布局，OCR提取文字，Redis Stream推送任务 |
| `table`           | parser_id=table           | 表格单独提取，保留行列结构                      | 表格解析器识别表格区域，转换为结构化数据               |
| `one`             | parser_id=one             | 整篇文档作为一个chunk                           | 不做分块，直接全文索引                                 |
| `knowledge_graph` | parser_id=knowledge_graph | 实体关系抽取，构建知识图谱                      | 命名实体识别+关系抽取，图数据库存储                    |

**Redis Stream消息队列触发流程：**

```plain
用户点击"解析" → API Server接收请求 → 写入Redis Stream → Task Executor消费 → 调用对应Parser → 生成chunks → 向量化 → 写入ES
```

**2. `do_handle_task` 主要逻辑**

| 阶段     | 功能            | 技术方案               |
| :------- | :-------------- | :--------------------- |
| 文档下载 | 从MinIO获取文件 | boto3客户端            |
| 文档解析 | 调用对应Parser  | DeepDoc/pdfplumber/OCR |
| 分块处理 | 按策略切分文本  | 语义分块/固定长度分块  |
| 向量化   | 文本→向量       | BGE-M3/SILICONFLOW API |
| 索引写入 | 存入ES          | Elasticsearch bulk API |

**3. DeepDoc PDF解析技术**

| 组件                 | 功能         | 文件位置                             |
| :------------------- | :----------- | :----------------------------------- |
| `pdf_parser.py`      | PDF主解析器  | `rag/deepdoc/parser/pdf_parser.py`   |
| `VisionFigureParser` | 图片/VLM解析 | `rag/deepdoc/parser/vision.py`       |
| `TableParser`        | 表格解析     | `rag/deepdoc/parser/table_parser.py` |
| `OCR`                | 文字识别     | PaddleOCR/内置OCR                    |

**PDF解析流程：**

```plain
PDF输入 → 版面分析 → 文字区域检测 → OCR识别 → 图片区域检测 → VLM描述（可选）→ 表格提取 → 分块 → 向量化 → 索引
```
