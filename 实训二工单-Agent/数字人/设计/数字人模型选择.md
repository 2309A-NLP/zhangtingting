## 一、语音识别（ASR）—— 5 种

表格





| 模型                  | 技术架构                                                     | 核心特点                                                     |
| :-------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **Whisper-tiny/base** | OpenAI，Encoder-Decoder Transformer。音频先转成对数 Mel 频谱图，经两层 CNN 降采样后进入 Transformer Encoder，再自回归解码出文本 token。tiny 39M 参数（4 层/384 维），base 74M（6 层/512 维） | 多语言通用，但中文场景 CER 偏高；base 是默认选项，平衡速度与精度 |
| **FunASR**            | 阿里达摩院，**Paraformer** 架构。非自回归，用 CTC 做单调对齐，再并行解码。支持字级时间戳和热词定制 | 中文识别远优于 Whisper，适合中文生产环境                     |
| **OmniSenseVoice**    | 阿里通义实验室，基于 **SenseVoiceSmall** 编码器，非自回归。多任务输出：识别 + 情感 + 音频事件。支持 50+ 语言，q8 量化仅 ~250MB | CPU 也能实时跑，延迟极低；quantize 版进一步压缩，非量化版精度更高 |

> Whisper 是"通用型"，FunASR/OmniSenseVoice 是"中文特化型"。

## 二、文本转语音（TTS）—— 6 条技术路线

表格





| 路线               | 技术架构                                                     | 核心特点                                                     |
| :----------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **Edge-TTS**       | 微软 Azure Neural TTS **云端 API**，非本地模型。HTTP 请求 → 云端深度神经网络合成 → 返回音频流 | 音质最好、情感最自然、多语言支持最全，但必须联网             |
| **PaddleTTS**      | 百度开源，**传统两阶段**参数合成。声学模型用 **FastSpeech2**（非自回归 FFT Encoder-Variance Adaptor-Decoder，输出 Mel 谱），声码器用 **PWGan** 或 **HiFi-GAN**（GAN 架构，Mel 谱反转为波形） | 完全离线、速度快、资源少，但音质机械感强，像"朗读腔"         |
| **GPT-SoVITS**     | RVC-Boss 团队，**语音克隆专用**。两阶段：GPT 模型负责语义/韵律预测，SoVITS 模型（基于 VITS 改进）负责声学特征生成。VITS 核心 = 变分推断 + 标准化流 + 对抗训练 | 3-10 秒参考音频即可克隆音色，支持跨语言，情感自然            |
| **CosyVoice-SFT**  | 阿里通义实验室，**生成式语音大模型**，基于 Transformer 端到端。SFT 版用微调后数据，适合预训练音色稳定输出 | 三种模式：预训练音色（零样本）、3s 极速复刻（zero-shot）、跨语种复刻（cross-lingual） |
| **CosyVoice-克隆** | 同上，基础版 CosyVoice-300M，更适合克隆和翻译任务            | 与 SFT 版共用架构，但训练数据侧重克隆能力                    |

> TTS 的技术代际：**Edge-TTS（云端 API）→ PaddleTTS（传统统计参数）→ GPT-SoVITS/CosyVoice（深度学习端到端/语音克隆）**。

## 三、数字人（Talking Head）—— 5 种

表格





| 模型          | 技术架构                                                     | 核心特点                                                     |
| :------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **SadTalker** | CVPR 2023，**3D 运动系数驱动**。核心是把人脸参数化为 3DMM（3D Morphable Model）系数：ExpNet 从音频预测表情系数（局部，与声音强相关），PoseVAE 预测头部姿态（全局，与声音弱相关），再用 facevid2vid 渲染成 2D 视频帧 | 默认模型。生成**头部运动 + 表情 + 口型**，风格化明显，不是纯口型同步 |
| **Wav2Lip**   | ACM 2020，**GAN 架构**。1 个生成器 + 2 个判别器：预训练唇同步专家判别器强制口型与音频对齐，视觉质量判别器保证真实感 | 高精度口型同步，但面部其他区域完全不动，像"只有嘴在动"       |
| **Wav2Lipv2** | Wav2Lip 改进版，分辨率提升到 288×288，新增 YOLO 面部检测     | 比原版更清晰，面部细节更好                                   |
| **NeRFTalk**  | 基于 **NeRF**（Neural Radiance Field）。用 NeRF 建模 3D 人脸，音频驱动视角渲染 | 3D 一致性最好，但**仅内置奥巴马模型**，上传其他图片无效，训练成本极高 |
| **MuseTalk**  | 腾讯音乐天琴实验室，**实时唇同步**。图像用 frozen VAE 编码，音频用 frozen Whisper-tiny 编码，生成网络借鉴 Stable Diffusion 的 UNet，音频嵌入通过 Cross-Attention 融合到图像嵌入。**关键：不是扩散模型，是潜在空间单步修复（latent space inpainting）** | 实时 30fps+，身份保持好，适合直播/实时对话。`bbox_shift` 参数控制嘴巴张开度 |

## 四、一句话总结各模块的技术代际

表格





| 模块   | 从旧到新                                                     |
| :----- | :----------------------------------------------------------- |
| ASR    | Whisper（通用 Transformer）→ FunASR/OmniSenseVoice（中文特化、非自回归） |
| TTS    | Edge-TTS（云端 API）→ PaddleTTS（传统两阶段）→ GPT-SoVITS/CosyVoice（端到端语音克隆） |
| 数字人 | Wav2Lip（GAN 口型同步）→ SadTalker（3D 运动系数）→ MuseTalk（实时潜在空间修复）→ NeRFTalk（NeRF 3D） |

表格
