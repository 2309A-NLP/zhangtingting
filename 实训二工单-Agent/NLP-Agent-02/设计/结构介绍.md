**一、顶层入口**
[main.py](D:/Desktop/NLP-Agent-02/src/app/main.py)

它是整个应用启动入口，负责创建 3 个 FastAPI 应用：

- `app`：API 服务
- `scheduler_app`：定时扫描服务
- `worker_app`：队列消费服务

它不做业务，只负责把这些东西组装起来：

- 日志
- 中间件
- 异常处理
- 路由
- lifespan 生命周期

**二、`api/`：接口层**
作用：对外暴露 HTTP 接口和 demo 页面。

关键文件：

- [demo.py](D:/Desktop/NLP-Agent-02/src/app/api/demo.py)

**十四、这些文件夹之间怎么联系**
最典型的调用链有 3 条。

**1. 普通业务接口链路**
`api/routes -> services -> repositories -> models/database`

例子：
`POST /schedule`
`route -> ScheduleService -> ScheduleRepository -> DB`

**2. Agent 对话链路**
`api/routes/agent -> AgentOrchestrator -> parser/llm_parser/planner -> executor -> tools -> services -> repositories`

例子：
“明天下午5点提醒我洗澡”
`agent.py -> orchestrator.py -> parser.py/llm_parser.py -> executor.py -> tools.py -> schedule_service.py -> schedule_repository.py`

**3. 提醒触发链路**
`scheduler job -> service -> repository -> queue -> worker service -> channel`

例子：
到点提醒
`reminder_jobs.py -> ReminderService -> ScheduleRepository -> Redis queue -> worker_jobs.py -> ReminderWorkerService -> channels/webhook.py or console.py`

- `channels`：把提醒发出去

- `core`：配置、数据库、日志、鉴权
- `utils`：通用小工具
