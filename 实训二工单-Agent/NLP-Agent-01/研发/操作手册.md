启动很简单，按这个顺序来。

一、先进入项目目录

cd /d d:\Desktop\NLP-Agent-01

如果你已经在这个目录里，就不用再切了。

二、创建并激活虚拟环境

python -m venv .venv

.venv\Scripts\activate

激活后，命令行前面一般会出现 `(.venv)`。

三、安装依赖

pip install -r requirements.txt

四、配置环境变量 项目里需要 `.env`。

如果你已经有 `.env.example`，就复制一份为 `.env`；如果没有，就自己新建一个 `.env` 文件，内容至少写这些：

OPENAI_API_KEY=你的_API_KEY

OPENAI_BASE_URL=https://api.openai.com/v1

MODEL_NAME=gpt-4o

DB_PATH=money_notes.db

LOG_LEVEL=INFO

MAX_DB_RETRIES=3

MAX_TOOL_CALL_ROUNDS=8

AGENT_MODE=langchain

最关键的是：

- `OPENAI_API_KEY`
- `OPENAI_BASE_URL`
- `MODEL_NAME`

五、启动项目

python main.py

启动后你会看到欢迎语，然后就可以直接输入：

今天妈妈买菜88元

或者：

看下这个月家里花钱明细

六、退出程序 输入下面任意一个即可退出：

退出

quit

exit

q

补充说明

1. 数据库会自动初始化
   `main.py` 启动时会自动执行 `init_db()`，所以你不用手动建表。
2. 数据库文件默认位置
   默认会在项目根目录生成：

- `money_notes.db`

1. 如果没配 API Key 会怎样
   虽然很多规则型功能已经写好了，但项目入口里仍然会加载 Agent 相关配置。
   所以如果环境变量不完整，运行时可能报错，最稳妥的方式就是把 `.env` 配好。
